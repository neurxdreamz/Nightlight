# 🌙 Проект «Ночник» (Nightlight)

Данный проект разработан в рамках Лабораторной работы №1. Представляет собой настольное приложение (WPF), демонстрирующее применение «Проектирования по контракту» в связке с архитектурным паттерном MVVM.

# 📌 Описание
Приложение эмулирует работу умного ночника. Вся бизнес-логика строго защищена контрактами (предусловиями и постусловиями). Интерфейс приложения реактивно реагирует на ввод пользователя, отображая статус выполнения контрактов в реальном времени с помощью визуальных индикаторов.

🛠 Технологический стек
Язык: C# 12

Платформа: .NET 10.0

UI Фреймворк: WPF 

Архитектура: MVVM (с использованием библиотеки CommunityToolkit.Mvvm)

Тестирование: nUnit


⚙️ Реализованные операции (Сюжеты)
Приложение поддерживает 3 основные операции. Каждая из них изолирована в собственной ViewModel и имеет строгий контракт:

1. Автоматическое включение по датчикам
Pre (Предусловие): Освещенность окружения должна быть в диапазоне [0, 100].

Post (Постусловие): Ночник включен тогда и только тогда, когда зафиксировано движение и в комнате темно (свет < 30).

2. Ручная установка яркости
Pre: Заданная яркость находится в диапазоне [1, 100].

Post: Значение текущей яркости обновлено, статус ночника переведен в состояние "Включен".

3. Таймер сна (Sleep Timer)
Pre: Ночник в данный момент включен, а заданное время задержки находится в диапазоне (0, 120] минут.

Post: Таймер успешно инициализирован, время зафиксировано, запущен фоновый отсчет. При истечении времени ночник переходит в выключенное состояние.

🛡 Архитектура контрактов
Контракты реализованы с помощью Триады Хоара {Pre} операция {Post}:

Проверка Pre: Осуществляется до выполнения логики через кастомный метод Guard.Requires(). При невалидных данных немедленно выбрасывается PreViolationException. В UI-слое кнопка выполнения блокируется.

Проверка Post: Осуществляется после выполнения логики через Debug.Assert(), гарантируя, что внутреннее состояние системы изменилось корректно.

# 🚀 Как запустить проект
Склонируйте репозиторий:

Bash
git clone https://github.com/neurxdreamz/Nightlight.git

Откройте файл решения Nightlight.sln в Visual Studio 2019+

Убедитесь, что установлен компонент .NET 10.0 Desktop Development (WPF).

Выберите проект Nightlight в качестве загружаемого по умолчанию (Set as Startup Project).

Нажмите F5 для запуска приложения.

# 🧪 Запуск тестов
Юнит-тесты проверяют поведение доменной модели на граничных значениях контрактов.

В Visual Studio откройте вкладку Тест (Test) -> Обозреватель тестов (Test Explorer).

Нажмите Выполнить все (Run All).
